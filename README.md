# Studio Namma Clone

A responsive frontend clone of the Studio Namma website, built using **HTML, CSS, and JavaScript**.

## 🚀 Live Demo

**GitHub Pages:**
https://jahanvi1405.github.io/Studio_Namma_Clone/

## ✨ Features

* Responsive website design
* Clean and modern UI
* Interactive elements using JavaScript
* CSS animations and hover effects
* Mobile-friendly layout
* Structured HTML and CSS
* Deployed using GitHub Pages

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* GitHub Pages

## 🎯 Purpose

This project was created to practice frontend web development by recreating the design and layout of the Studio Namma website.

It helped me improve my understanding of:

* Semantic HTML
* CSS Flexbox and layouts
* Responsive web design
* CSS animations and transitions
* JavaScript DOM manipulation
* Git and GitHub
* Website deployment

## 📱 Responsive Design

The website is designed to work across:

* 💻 Desktop

* 📱 Tablet
* 📱 Mobile
